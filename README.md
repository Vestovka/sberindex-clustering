# SberIndex: Кластеризация муниципалитетов

Проект для конкурса СберИндекса. Задача — выявление экономической структуры
российских муниципалитетов через кластеризацию на атрибутированных сетях.

## Что делает проект

1. Собирает экономические данные по муниципалитетам (расходы, мобильность, зарплаты).
2. Строит граф, где узлы — МО, а рёбра — экономическая близость.
3. Кластеризует МО по типам локальных экономик.
4. Отслеживает изменения кластеров во времени.
5. Визуализирует и интерпретирует результаты.
